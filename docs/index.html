为什么用 Collie

agent 在干活，你不用守着屏幕

它们跑在你自己的电脑上，Collie 只负责让你随时看得到、管得到。

四级智能派活与休眠容灾默认自动派活：自动识别项目所在电脑并避开欠费或耗尽的账户；主脑电脑休眠时自动漂移至在线电脑接管。
桌面端无锁共聊与中途插话与 Codex App 等桌面端共享同一会话不冲突，支持运行中实时插话、一键中止、过程折叠与提问卡片回复。
Mac · Win · Linux 合在一处各台电脑通过 collie node 主动加密外连云端 Hub：不开端口、不配 SSH，离线项目快照照常保留。
多机模型剩余用量与飞书预警右上角按电脑与 Agent 实时汇总配额百分比、重置时间与 API 余额；额度不足或任务待确认时飞书卡片直达。
跨机产物预览与 ⌘K 全文检索图片放大灯箱、PDF 内嵌预览、CSV 表格渲染、Office/压缩包一键跨机下载；⌘K 毫秒级检索跨机历史对话正文。
单个二进制，零外部依赖单个 Go 程序 + SQLite + 纯净无构建内嵌前端。支持 Hub 本地镜像极速安装与升级，数据完全自主可控。

Super-agent

说一句话，Collie 去组织

你只和 Collie 对话。它常驻在 hub 上，把事情拆成任务交给 worker，worker 做完、卡住都会回报，Collie 再决定下一步。

  • 选哪个 agent、哪台电脑、哪个模型，它根据上下文自己定
  • GitHub 评论、飞书消息、定时器都能变成任务
  • 越用越会派活：记住你的偏好和每次干活的经验，下次派活直接带上

手机上处理

需要你的时候，叫你一声

卡住的 agent 置顶，标签页标题带计数，后台时弹通知。打开就是一张决策卡片：编号菜单发数字，光标菜单发方向键，都替你处理好了。

  • 扫码配对，添加到主屏幕就是一个 app
  • 窄屏有专门的布局，单手就能回

项目模式与直接对话

项目工作区与每个会话都能无缝接手

侧边栏按「项目 → 会话」清晰组织，支持交互式跨机目录树浏览与宿主机项目同步。点开任意会话即可切换模型与思考强度、实时插话或预览跨机生成的图表与文档。

  • 桌面端 Codex / Claude 会话与终端会话实时同步，无需退出桌面 App 即可直接对话
  • 推理与工具调用在执行中实时流式展开，完成后自动折叠为紧凑抽屉，只留清爽结论

Always-on

事件进来，Collie 决定谁去做

你的消息、webhook、定时器和 worker 的回报都进同一个收件箱。先按来源策略过滤，订阅了线程的 worker 直接收到，其余交给 Collie 判断。

  • 记忆按用途分开：你的偏好、进行中的任务、按项目整理的笔记，每晚「做梦」整理一次
  • 所有状态都在 SQLite，Collie 随时可以重启，事件不会丢

架构

hub 常开，电脑连上来

一个 hub 放在常开的开发机上；其他电脑运行 collie node 主动连上 hub；手机、平板、浏览器只连 hub。agent 本身跑在 herdr 里，关掉网页也不停。

轻量单二进制Go 编写，无构建纯净前端内嵌，无需任何外部 CDN
出站加密隧道yamux 多路复用长连接，休眠唤醒断线自动重连
实时配额感知多机模型余量一览，自动避开欠费或耗尽账户
镜像极速更新优先走 Hub 本地镜像下载并自动完成签名与原地重启

安装

两分钟装好

macOS、Linux、Windows（amd64 / arm64）。下载会校验 SHA-256，装成后台常驻服务；没有 herdr 的话顺便装上。

在一台常开的开发机上运行。之后用手机扫终端里的二维码就能登录。

curl -fsSL https://raw.githubusercontent.com/Tdcle/collie/main/docs/install.sh | sh -s -- hub

在 macOS / Linux 电脑上运行。hub 地址和配对码在 hub 的「设备 → 连接一台电脑」里拿；电脑主动连 hub，不用开端口。

curl -fsSL https://raw.githubusercontent.com/Tdcle/collie/main/docs/install.sh | sh -s -- node --hub http://<hub>:7788 --code <配对码>

在 Windows PowerShell 里运行。会自动安装或编译 collie.exe、检测/安装 herdr，并注册后台常驻与登录自启。

powershell -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Tdcle/collie/main/docs/install.ps1))) node --hub http://<hub>:7788 --code <配对码>"

只把 collie 装到 ~/.local/bin，不装服务。

curl -fsSL https://raw.githubusercontent.com/Tdcle/collie/main/docs/install.sh | sh

需要 Go 1.25+。在仓库里运行安装脚本，会用本地源码编译；后面可以接 hub 或 node --hub … --code …。

git clone https://github.com/Tdcle/collie.git
cd collie
sh docs/install.sh hub

install.sh · install.ps1 · 完整文档

  1. 开发机上起 hub跑上面的「做 hub」。装好 herdr 的 agent 集成：herdr integration install claude。
  2. 手机扫码扫终端里的二维码，每台设备一个令牌，添加到主屏幕后就像一个 app。
  3. 其他电脑加入在「设备 → 连接一台电脑」里拿命令，在那台电脑上跑一下就连上了。
